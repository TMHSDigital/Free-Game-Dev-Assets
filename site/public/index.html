What the labels mean
active
License spot-checked at the source; the entry carries dated evidence.
needs-review
Useful, but a real question is open. Verify before you ship.
deprecated
Kept for history only. Hidden unless you turn it on.
commercial OK
The source grants commercial use.
per-file review
An aggregator. Some files qualify, some do not. Check each one.
commercial ?
The source does not say plainly. Treat as unresolved.
verified date
When someone last read the license at the source. Older than a year is worth re-checking yourself.

Fuller guidance is in the guides.

Commercial OK also keeps per-file review sources: aggregators where some files allow commercial use and some do not. Check the licence of each file you take.
