# FiveM / GTA-format assets

Catalog policy, not legal advice. Re-read the live Cfx, Rockstar, and source-license pages before you ship anything.

This catalog indexes original-work meshes and software that can write GTA-format files. It does not index Grand Theft Auto or Red Dead Redemption game files, extracts from those files, or "free FiveM prop" dumps.

## What is in scope

- CC0 / clearly licensed original 3D (Kenney, KayKit, Quaternius, Poly Haven, and similar verified entries)
- Tools whose software license we verified (currently [Sollumz](../catalog/tools/sollumz.md) and [Blender](../catalog/tools/blender.md))
- Your own models, exported to ydr / ytyp / ymap if you hold the rights to those models

## What is out of scope

- ydr / ytd / ytyp / ymap / ydd taken from GTA V or RDR2 RPF archives
- MLO leaks, escrow bypasses, Tebex reuploads, and anonymous GitHub fivem-props trees with no named author license
- Treating [Cfx Marketplace](https://marketplace.cfx.re/) or [FiveM Releases](https://forum.cfx.re/c/development/releases/7) as a blanket commercial library

Owning GTA V (required to run FiveM) licenses playing the game. It is not a license to redistribute Rockstar drawables, textures, or maps.

## Cfx is not a license grant

Cfx documents how to stream custom resources and how to author GTA-format content. Those manuals are not an asset pack. Live Finding Resources page (2026-08-25): "Use resources at your own risk" and "follow each resource's terms and conditions."

Paid / escrow resources stay under the seller's terms. Free forum posts are per-author. Convert a CC0 Kenney chair; do not convert a Rockstar chair.

## Tool license vs mesh rights

GPL on Blender or Sollumz covers the program. It does not copyleft a mesh you modeled, and it does not relicense GTA V files you import. Importing a Rockstar drawable into Blender does not make it CC0.

CodeWalker is not catalogued here: the GitHub repo has no LICENSE file, and it reads GTA V archives. Sollumz mentions it as a companion; that is not a rights grant.
