# Kenney Tiny Battle

190 CC0 16x16 tiles for turn-based strategy maps: terrain, roads, rivers, bridges, buildings, and coloured unit markers for several factions. Overhead wargame layout in the Advance Wars mould, which no other catalog entry covers.

## Notes

- Units are map markers, not animated characters. There are no walk cycles here; pair with a character pack if you need figures on the field
- Faction colours are baked per unit sprite rather than supplied as a mask, so a fifth faction means recolouring by hand
- Terrain is orthographic overhead and matches [kenney-micro-roguelike](kenney-micro-roguelike.md) in projection but not in grid size (16x16 versus 8x8)
- Same Kenney CC0 grant as the rest of the Kenney entries here; no attribution required
