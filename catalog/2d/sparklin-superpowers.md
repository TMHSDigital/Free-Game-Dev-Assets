# Sparklin Superpowers asset packs

Pixel-Boy packs from Sparklin Labs (vehicles, prehistoric platformer, space shooter, RPG battle UI, and more). One GitHub repo, one CC0 grant. Ninja Adventure is a different catalog entry. Do not treat this hub as a second ninja id.

## Notes

- Repo README (2026-08-29): assets "released under the Creative Commons Zero (CC0) license." `LICENSE.txt` is the full CC0 1.0 deed.
- Same README: "You can use the assets found in this repository in your own games, even commercial ones. Attribution is not required but appreciated."
- 2D folders named this session (exclude ninja): `prehistoric-platformer`, `space-shooter`, `top-down-shooter`, `western-fps-2d`, `rpg-battle-system`, `medieval-fantasy`, `backgrounds`.
- Same repo also has `3d-character` and `3d-vehicles`. Same CC0 file. Not separate catalog ids this wave.
- Itch download hub: [sparklinlabs.itch.io/superpowers](https://sparklinlabs.itch.io/superpowers). Prefer GitHub `LICENSE.txt` as the grant.
- Ninja stays [ninja-adventure](ninja-adventure.md) (Pixel-Boy itch pack).
