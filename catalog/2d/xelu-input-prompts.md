# Xelu input prompts

Keyboard and gamepad prompt icon sets from Those Awesome Guys (Nicolae Berbece / Xelu), updated by Paul Paun (2021). CC0 for personal and commercial projects. Prefer Kenney Input Prompts when you need Switch 2, Meta Quest, Playdate, or Steam Frame glyphs.

## Notes

- Live page offers one zip (`Xelu_Free_Controller&Key_Prompts.zip`) and points at a Readme.txt inside
- Frontmatter formats stay PNG; the page itself does not list SVG
- Coverage is the older "industry standard" pad set; Kenney's pack is the hardware-current alternative
