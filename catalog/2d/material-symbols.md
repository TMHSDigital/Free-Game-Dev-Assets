# Material Symbols

Google's variable icon font (outlined / rounded / sharp) plus SVG, the system-style HUD set this catalog was missing next to Lucide/Tabler/Phosphor. The fonts.google.com/icons page is a JavaScript app and yielded no license body on 2026-08-24. The grant we can quote is `LICENSE` in [google/material-design-icons](https://github.com/google/material-design-icons): Apache License 2.0. Apache permits commercial use. Keep the licence text when you redistribute the font files.

## Notes

- Do not confuse with Font Awesome. Material Symbols are generic UI glyphs. Brand-mark rules still apply if you draw a third-party logo with them
- Variable font is the practical game path (one file, weight axis). SVG export is for atlases
- GitHub README (2016): "License change to Apache 2.0". That is historical; current `LICENSE` is still Apache 2.0
- Prefer [lucide-icons](lucide-icons.md) if you want a smaller brand-free SVG set with a simpler ISC grant
- Keep the Apache-2.0 licence text with redistributed copies of the font or SVG files (section 4(a)); the repository ships no NOTICE file, and no on-screen credit is required. Google's README says an about-screen credit is welcome but optional
