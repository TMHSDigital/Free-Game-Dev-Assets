# Wikimedia Commons

The media repository behind Wikipedia: tens of millions of photographs, diagrams, maps, scans and SVG drawings, each uploaded under its own free licence or as public domain. Useful for reference images, textures, historical material and vector maps, as long as each file's own licence is read.

## Notes

- Licences differ per file: public domain, CC0, CC BY and CC BY-SA are the common ones, and share-alike files carry their licence to adaptations.
- Per item: open each file's description page and read the licence and author listed there; public-domain files may not legally need credit, but Commons recommends crediting the source anyway.
- Source: added for #100 (catalog coverage gaps); the licence was read at the source on 2026-11-18.

- Live [Reusing content outside Wikimedia](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia) (2026-11-18): "Except for materials believed to be in the public domain, a link to the full text of the license(s) is included on the file description page."
- Same page (2026-11-18): "Content in the public domain may not have a strict legal requirement of attribution (depending on the jurisdiction of content reuse), but attribution is recommended to give correct provenance."
