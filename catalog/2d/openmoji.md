# OpenMoji

An open-source emoji and icon set in one consistent outline style, covering the Unicode emoji plus extra icons, as SVG and PNG.

## Notes

- Share-alike: changed versions of the emoji must carry the same licence. Using them unchanged in a game still needs the credit.
- Source: added for #100 (catalog coverage gaps); the licence was read at the source on 2026-11-18.
