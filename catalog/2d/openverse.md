# Openverse

A search engine for openly licensed images and audio, run by WordPress, that indexes CC-licensed and public-domain works hosted on other sites. It finds candidates quickly; the licence that counts is the one on the hosting site.

## Notes

- Openverse does not host the files or check their licences; every result links to the site that does.
- Per item: open each result's source page and confirm the licence there before use, then credit as that licence asks.
- Source: added for #100 (catalog coverage gaps); the licence was read at the source on 2026-11-18.

- Live [Terms of Service](https://docs.openverse.org/terms_of_service.html) (2026-11-18): "Openverse aggregates metadata about openly licensed content hosted on websites managed by third parties."
