# Kenney Micro Roguelike

320 CC0 8x8 1-bit tiles: dungeon and overworld terrain, creatures, items, and UI glyphs drawn orthographically from above. This is the catalog’s clearest true top-down tileset, as opposed to the 3/4 overworld style that most pixel RPG packs use.

## Notes

- 8x8 is half the usual pixel grid, so this does not mix with the 16x16 packs here without integer scaling. Pick the grid before you build the tilemap, not after
- 1-bit monochrome: the pack ships one foreground colour. Recolour per biome in-engine with a shader or modulate, rather than exporting variants
- Orthographic overhead, so walls read as thin lines rather than facades. Do not mix tiles from a 3/4 pack like [kenney-tiny-town](kenney-tiny-town.md) into the same map
- Closest sibling in style is [urizen-onebit](urizen-onebit.md) at 12x12, which is 3/4 rather than ortho
