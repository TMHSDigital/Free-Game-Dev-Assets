# Rotating Gems for Match-3 (Bondoki)

Animated gems made for a match-3 game, CC0, from 2021: seven colours, plus heart-bomb and rainbow-bomb special pieces in each colour and three rainbow gems.

## Notes

- 40-frame rotation animations at 52x52 pixels per tile, per the author
- **Delivered as animated GIFs**, one per gem and special piece, plus one PNG (`gem_bomb_rainbow.png`). The description says PNG; the animations themselves are GIFs. For an engine, split the GIF frames into a sprite sheet
- No bundled licence file; the CC0 is the OpenGameArt licence field. See [`docs/provenance.md`](../../docs/provenance.md)
- For vector gems you can recolour and scale, see [sylly-gem-match-3](sylly-gem-match-3.md)
