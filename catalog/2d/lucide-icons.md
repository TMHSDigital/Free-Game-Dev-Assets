# Lucide Icons

1780 consistent, brand-free UI icons under ISC. Safer than logo-heavy sets for generic HUD chrome. Complements Game-Icons.net (game-flavored) versus Lucide (product UI). Keep the ISC copyright notice when you redistribute the icon sources.

## Notes

- Live site [license](https://lucide.dev/license) matches GitHub `LICENSE`
- A listed subset is derived from Feather and is MIT rather than ISC; the notice names those glyphs
- Tree-shakable packages for JS frameworks; for Godot/Unity, import SVGs or a subset atlas
- Homepage marketing does not print the license; the /license page does
