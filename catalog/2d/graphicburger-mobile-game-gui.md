# Mobile Game GUI

A colourful, cartoon-style interface kit for 2D mobile games from GraphicBurger, published in September 2013. It ships as one layered Photoshop file (5.2 MB zip) built from vector shapes and layer styles, so buttons, panels and bars can be resized and recoloured before you export them to PNG for your engine. It is listed on awesome lists as "2D Cartoon Mobile Game UI Pack"; the publisher's own title is Mobile Game GUI. The GraphicBurger licence allows personal and commercial projects with no credit, but the source files may not be redistributed on their own.

## Notes

- Licence: GraphicBurger's site-wide licence, not a Creative Commons licence. Commercial use in your own or a client's projects is allowed; no attribution is required.
- Redistribution: the licence forbids reselling, sublicensing or redistributing the files "on its own", even for free. Ship the exported art inside your game; do not put the PSD in a public repository or an asset bundle.
- Site quirk: on 2026-09-30 the licence page at graphicburger.com/license/ returned HTTP status 404 while still rendering the full licence text, which is probably why an earlier triage recorded it as dead. The download link returned a 5.5 MB zip the same day.
- Format: layered PSD needing Photoshop CS4 or later. GIMP and Photopea can open it, but layer styles may not render identically outside Photoshop.
