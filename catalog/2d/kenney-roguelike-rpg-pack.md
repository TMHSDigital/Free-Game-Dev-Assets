# Kenney Roguelike/RPG Pack

1700 CC0 16x16 tiles covering an entire RPG: overworld terrain, town buildings, interiors, furniture, items, and a matching UI panel and button set. The largest single 2D tile pack in this catalog and the one that gets a prototype furthest without leaving one art style.

## Notes

- The UI panels and buttons are counted in the 1700 and are 16x16-grid art, not a scalable nine-slice kit. For resizable HUD chrome use [kenney-ui-pack](kenney-ui-pack.md) instead
- Ships as a spritesheet plus individual PNGs; the sheet needs slicing on the 16x16 grid before an engine tilemap will read it
- 3/4 view like [kenney-tiny-town](kenney-tiny-town.md), so it is a superset of that style rather than a companion to the orthographic packs
- Breadth over depth: many props have a single frame, so animation is on you
