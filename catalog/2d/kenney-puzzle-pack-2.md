# Kenney Puzzle Pack 2

About 800 CC0 sprites for casual puzzle games: coloured tiles and back tiles, balls, paddles, pipes, coins and particle bursts. Built for brick-breaker, pipe-connection and tile-clearing games. The catalog's first dedicated puzzle-game art.

## Notes

- **Measured from the download, 2026-09-23:** 814 PNGs in folders by type and colour (`Back tiles`, `Balls/Blue`, `Paddles`, `Pipes/Green`, `Particles yellow`, `Tiles black` and more), plus SVG sources and XML sprite sheets
- Not match-3 gem art. There are coloured tiles and balls, but no faceted gems; for a Bejeweled-style game this is a starting point, not a finished set
- Also contains `.swf` files, a leftover of 2015-era Flash workflows. Ignore them
- Pair with [kenney-ui-pack](kenney-ui-pack.md) for menus and [kenney-interface-sounds](../audio/kenney-interface-sounds.md) for clicks and pops
- Kenney lists a "Puzzle Pack 1" alongside this; the old `puzzle-pack` URL now returns 404, so this entry is the second pack only
