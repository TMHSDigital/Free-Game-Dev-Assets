# Kenney Tiny Town

130 CC0 16x16 tiles for an RPG overworld town: houses, roofs, fences, trees, paths, and a handful of villagers. Drawn in 3/4 view, so buildings show a front facade above an overhead ground plane.

## Notes

- Exteriors only. There are no interior floors or dungeon tiles; [kenney-tiny-dungeon](kenney-tiny-dungeon.md) is the matching interior set at the same grid and style
- 130 files is a small set. It builds a convincing village and runs out quickly if you need a whole region
- 3/4 view, not orthographic. Mixing it with [kenney-micro-roguelike](kenney-micro-roguelike.md) or [kenney-tiny-battle](kenney-tiny-battle.md) will read as a projection error
- The villager sprites are scenery figures, not a playable character set
