# Game-Icons.net

4000+ monochrome SVG icons (weapons, spells, status, UI). Infinitely scalable; CC-BY-3.0 on the site. A few GitHub contributors (e.g. Viscious Speed, Zeromancer) are CC0 — check the author folder.
