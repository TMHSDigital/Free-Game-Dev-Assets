# Gem Match 3 Set (Sylly)

Four gem shapes in six colours for a match-3 game, by Andrew Tidey (Sylly), CC0, with a vector source. Static pieces: pair with your own tweens for swaps and pops.

## Notes

- **Measured from the download, 2026-09-23:** 73 PNGs under `PNG/` (for example `PNG/Large/Gem Type1 Blue.png`), one SVG source, and a `License.txt`
- The SVG means you can re-render at any resolution or add colours, which matters on high-density phone screens
- No special pieces (bombs, rainbows); for those, see [bondoki-rotating-gems](bondoki-rotating-gems.md)
