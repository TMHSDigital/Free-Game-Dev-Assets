# Glitch archive

10k+ drawings, sprites, and backgrounds from the shuttered MMO Glitch. Tiny Speck dedicated the art to the public domain under CC0. This entry is the items repo; sibling Tiny Speck repos (locations, avatars, etc.) are the same grant, not extra catalog ids.

## Notes

- Logo and trademark are excluded. Only files in the repo tree are covered.
- Original announcement: glitchthegame.com/public-domain-game-art/ (not re-fetched this session). Community PNG/SVG conversions are usually easier than Adobe FLA.
- FLA packages need Flash-era tools or community rips; do not treat FLA as engine-ready.
- OpenGameArt post is a news quote of Tiny Speck, not a per-file OGA widget. Keep it in Related.

## Evidence

- Live `tinyspeck/glitch-items` README (2026-08-29): "All files are provided by Tiny Speck under the Creative Commons CC0 1.0 Universal License."
- Same README (2026-08-29): "the Glitch logo and trademark are not among the things we are making available under this license."
