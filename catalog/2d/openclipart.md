# Openclipart

Large SVG clipart library (FAQ: 180,000+ files) that the site places under CC0 1.0 on every upload. Unlimited commercial use is stated on the FAQ. Attribution is not required. The caveat is provenance, not the license text: librarians tag doubtful files `pd_issue`, and a CC0 click-through is not a chain-of-title audit. Skip anything that looks like a trademark, a photo trace, or a `pd_issue` flag. Prefer [game-icons-net](game-icons-net.md) / [phosphor-icons](phosphor-icons.md) when you want named authors and a smaller, cleaner set.

## Notes

- License FAQ: [openclipart.org/share](https://openclipart.org/share)
- Download the SVG from the clipart page. Safari "save page" will grab HTML if you left-click
- Raster PNG derivatives exist on the site. The canonical file is SVG
- This is a community dump with volunteer librarians, not an anonymous torrent. It is still not a rights-cleared studio library
- Checklist: CC0 named on the FAQ, commercial yes, no attribution required, not a marketplace EULA, site is long-running with a librarian role, not blocklisted, catalog claims no rights, `pd_issue` trap recorded
