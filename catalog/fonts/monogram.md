# Monogram

Compact monospace bitmap font by datagoblin, legible at small sizes, released CC0. Offered as TrueType, as a bitmap sheet with JSON metrics, and as a PICO-8 custom font. An extended version adds more glyphs and an italic.

## Notes

- Name-your-own-price on itch; the free download includes every font file (a "thank-you gift" zip is for payments of $5 or more)
- Files listed on the download page (2026-09-26), version 1.1.0: `monogram.ttf`, `monogram-extended.ttf`, `monogram-extended-italic.ttf`, `monogram-bitmap.png`, `monogram-bitmap.json`, `monogram.p8`
- CC0, so no notice file has to ship with the font
