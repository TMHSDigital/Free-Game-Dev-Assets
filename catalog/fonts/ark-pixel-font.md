# Ark Pixel Font

TakWolf pan-CJK gothic pixel face (10 / 12 / 16px, monospaced and proportional, language-specific glyphs). Second pixel CJK option besides DotGothic16. SIL OFL 1.1 on the font; MIT is build tools only.

## Notes

- README (2026-08-29): still missing a large number of Han characters. Treat coverage as incomplete.
- Prefer 12px for real coverage. README suggests Fusion Pixel Font as a stopgap for 8/10/12px and Unifont for 16px.
- `LICENSE-OFL` copyright line has no Reserved Font Name. Do not invent "方舟像素" / "Ark Pixel" as an RFN.
- Keep `LICENSE-OFL` with redistributed font files. Do not sell the font standalone.
- Attribution example (optional): `Ark Pixel Font (c) TakWolf. SIL OFL 1.1`
