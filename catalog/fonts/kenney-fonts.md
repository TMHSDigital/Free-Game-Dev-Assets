# Kenney Fonts

Twelve CC0 TrueType fonts from Kenney: pixel faces (Pixel, Mini, High, each with a Square variant, plus Mini Square Mono) and display faces (Future, Future Narrow, Blocks, Rocket). They match the lettering in many Kenney UI and game packs, so they suit HUDs built from [kenney-ui-pack](../2d/kenney-ui-pack.md).

## Notes

- CC0, so unlike the OFL fonts in this folder there is no licence file you must ship with the font
- Contents read from the download ZIP (2026-09-26): 12 `.ttf` files and `License.txt`
- Version 1.0, released 2014 per the pack page
- Attribution example (optional): `Fonts by Kenney.nl (CC0)`
