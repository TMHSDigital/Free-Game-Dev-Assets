# Open Foundry

Curated gallery of open-source type (Work Sans, Inter, League Gothic, and others). Useful as a *discovery* index, not as a download CDN. About: featured fonts have "an open-source licence such as SIL, MIT"; commercial use is "Often yes, but it depends on the licence of each individual font"; Open Foundry does **not** distribute the files. Downloads live on the designer's project page. If this site and the upstream OFL.txt disagree, About says the original project page prevails.

## Notes

- About: [open-foundry.com/about](https://open-foundry.com/about)
- "Open Foundry is a non-commercial project" describes the *gallery*, not a ban on using OFL faces in a commercial game
- Do not scrape the preview files they host for on-site rendering
- League Gothic appears here; this catalog already has [orbitron](orbitron.md) from The League. That is why a League foundry entry was not added (same publisher domain as Orbitron's `url`)
- Checklist: license policy in HTML, commercial per-font, attribution per-font, not a marketplace EULA, named curator, not blocklisted, no rights claimed
