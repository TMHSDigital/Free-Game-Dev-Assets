# Piskel

Free browser-based editor for animated sprites and pixel art, with a live animation preview, onion skinning and layers. It exports animated GIFs, PNG sprite sheets or ZIPs of frames. It runs locally in the browser with no account, which makes it the fastest way to rough out a sprite animation.

## Notes

- Apache-2.0 covers the editor's code. The site's terms say you keep all rights to artwork you create, and a credit is requested but not required
- The site does not store your work and has no autosave, so export or save before closing the tab
- The GitHub repository is active (last push 2026-09-29, read 2026-09-30), but the downloadable desktop build is old. Its latest GitHub release is v0.15.0 from 2018-11-25, so prefer the web version
- Apache-2.0 notice duties apply only if you redistribute Piskel's code, not to sprites you export
