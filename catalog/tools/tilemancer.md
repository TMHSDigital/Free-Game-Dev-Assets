# Tilemancer

Node-based procedural tile generator for pixel-art games. You build a heightmap from noise generators and filters, and the program shades it into a tile. Nodes and presets are Lua scripts, so you can write your own. It is quick for game-jam terrain and texture variations. The Windows and macOS downloads are name-your-own-price on itch.io.

## Notes

- GPL-3.0-or-later covers the program, per the licence and source headers in `Ledgamedev/Tilemancer`. That repository belongs to the same author, "Led", and its last commit is the 0.2.1 update, the version itch.io serves. Tiles you generate are your own output; the GPL only matters if you redistribute or modify the program
- Maintenance: the itch page says that "As of 03/04/2019, Tilemancer is officially no longer in development". The last push to `Ledgamedev/Tilemancer` was 2016-07-04 (read 2026-09-30). It is still downloadable
- The itch community board has a thread titled "Tilemancer No Longer Works on Mac". Expect the Windows build to be the one that runs
- The author's successor, Tilesetter, is a separate commercial product and is not covered here
