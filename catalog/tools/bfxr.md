# Bfxr

increpare's browser sfxr descendant (current app is Bfxr2 in JavaScript). More parameters than [jsfxr](jsfxr.md), plus a port of obiwannabe's footstep generator. Use it when ChipTone's CC0 output grant is what you wanted and jsfxr is too thin, knowing this page does **not** CC0 the WAVs. The software is MIT. Homepage About does not discuss output ownership. Sounds you generate are not a redistribution of someone else's pack, but that is inferred, not quoted.

## Notes

- App: [bfxr.net](https://www.bfxr.net). Source: [github.com/increpare/bfxr2](https://github.com/increpare/bfxr2) `LICENSE` (MIT, Stephen Lavelle)
- Export is WAV via Ctrl+E. `.bfxr` / `.bcol` are project files, not engine assets
- Old Flash Bfxr is linked as `/v1`. This entry is the JS rewrite
- Checklist: MIT file on GitHub, commercial use of the *code* allowed, no NC/ND, not a marketplace, named author, not blocklisted, tool vs WAV ownership unquoted (unlike ChipTone)
