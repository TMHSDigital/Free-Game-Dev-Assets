# Pixel Composer

Node-based editor by MakhamDev for procedural pixel-art effects and animation: particles, explosions, shaders and sprite processing built as node graphs. The source is MIT on GitHub. The ready-built Windows, macOS and Linux binaries are not free: itch.io sells them at $15 or more and Steam sells them too, with a free itch demo. Free here means building from source. It is listed in tools, not shaders-vfx, following [material-maker](material-maker.md) and [pixelorama](pixelorama.md): it is an editor that makes effects, not a pack of effects.

## Notes

- Building from source needs GameMaker, and the README lists YellowAfterLife's Apollo extension ($15) for the Lua nodes. Budget for that, or buy the binary
- MIT covers the editor's code. What you render with it is your own work; bundled example art is credited on the itch page to other artists (DantePixels, zrghr), so do not ship those samples
- itch metadata: "No generative AI was used"
- Maintenance: GitHub API on 2026-09-30 shows a push that day
