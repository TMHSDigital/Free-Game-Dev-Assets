# Paint.NET

Windows image editor that started as a free replacement for Microsoft Paint and grew into a layered editor with effects and a large plugin ecosystem. It is lighter than GIMP or Krita, and many texture and UI workflows only need that much. The current release is 5.1.12.

## Notes

- `custom`: proprietary freeware. The "Classic" release from the website is free. The Microsoft Store release is paid and has the same features plus automatic updates
- The licensing FAQ allows business and commercial use outright. The images you edit are not the program's concern
- The main restriction is that you may not modify Paint.NET or distribute modified copies. Its DLLs may not be used inside your own software
- Forum plugins belong to their authors. You may not redistribute them without permission
- Windows only. The old `getpaint.net` address now redirects to `paint.net`
