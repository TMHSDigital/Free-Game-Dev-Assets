# Spritemate

A browser-based sprite editor for the Commodore 64 by Ingo Hinterding (awsm). It enforces the C64's 24x21 sprite size and single-colour or multicolour modes, previews animation, and saves to SpritePad formats, assembly source (KickAssembler and ACME), BASIC listings or PNG images and sprite sheets. It is the tool to reach for when building a real C64 or C64-styled homebrew game; for general pixel art use [libresprite](libresprite.md) or [pixelorama](pixelorama.md). The source is MIT on GitHub and was still being updated in September 2026.

## Notes

- Licence of the tool: MIT, per the LICENSE file in Esshahn/spritemate. The hosted site at spritemate.com runs the same code in the browser; no account is needed.
- Your output: the sprites, assembly and BASIC data you export are your own work. The MIT licence covers the editor's code, not what you draw.
- Import: PNG images and sprite sheets, SpritePad files and VICE snapshots, so existing C64 sprites can be pulled out of a running emulator session.
- Maintenance: last push to Esshahn/spritemate on 2026-09-10, per the GitHub API on 2026-09-30.
