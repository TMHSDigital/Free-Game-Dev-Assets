# TrenchBroom

Brush-based 3D level editor for Quake-engine map formats, on Windows, macOS and Linux. With [func-godot](func-godot.md) the `.map` files it writes import straight into Godot, which makes it a blockout and level tool for Godot projects as well as Quake-family ones.

## Notes

- The GPL covers the editor. Maps you author are your own work; the GPL does not attach to them because you used a GPL program to make them
- Shipping TrenchBroom itself, or code taken from it, inside a closed product is a GPL event
- Supported games per the homepage: Quake, Quake 2 and Hexen 2; others through game configurations
