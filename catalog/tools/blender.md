# Blender

Free 3D DCC (model, UV, rig, animate, simulate). Listed here because GTA-format add-ons such as [Sollumz](sollumz.md) require Blender 4.0+, and the catalog had no blender.org tool entry. Software is GNU GPL. Artwork you make in it is a separate question, answered on blender.org.

## Notes

- Live FAQ "Can I use Blender commercially?": yes, and creations are the artist's property. That is the output-ownership statement.
- Source at blender.org is GPL Version 2 or later. Binary distributions are GPL Version 3 or later. Add-ons that use the Blender Python API are GPL if published.
- `.blend` files are program output and "the sole copyright of the user," unless you embed Python that pulls in other licensed code.
- Splash, icons, and the Blender logo are not a free asset pack. Do not ship the trademarked logo as game art.
- Blender Studio CC0/CC-BY bundles are separate catalog entries (Human Base Meshes, Ellie poses), not this tool.

## Evidence

- Live FAQ "Can I use Blender commercially?" (2026-08-25): "Any creation you make as an artist with Blender is your sole property"
- Live FAQ "Can I license .blend files myself?" (2026-08-25): "The output of Blender, in the form of .blend files, is considered program output"
- Live `/about/license/` (2026-08-25): "GNU GPL Version 2 or later" (source); binaries "GNU GPL Version 3 or later"
