# Material Maker

Node-based procedural PBR / texture authoring. FOSS alternative pathway to Substance-style graphs. Homepage calls it open source; the GitHub LICENSE.md is MIT. That is the editor license, not a blanket license on every community asset on the site.

## Notes

- Export PNG maps for engines; `.mm` is the graph source
- Confirm license on any downloaded community material separately from the editor MIT
