# Palette Extractor (SpriteWright)

Single-page browser tool that pulls the palette out of a sprite, tileset or photo. It lists exact colours for pixel art or median-cut reduces a photo to a set size. It exports a `.gpl` palette for Aseprite, GIMP, Krita or Inkscape, a Lospec `.hex` list, CSS variables, JSON or a PNG swatch strip. Everything runs client-side, so the image never leaves your machine.

## Notes

- MIT covers the tool's code, in the `pixelpixi/spritewright` repository. A palette taken from someone else's art is a list of colours. The art itself keeps its licence
- The same site sells paid Aseprite extensions. They are separate products and are not covered here; one of them, PaletteOut, is also free
- The `LICENSE` copyright line names "violetpixel13", not the `pixelpixi` account that hosts it. It is the same MIT grant either way
