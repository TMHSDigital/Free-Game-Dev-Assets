# ChipTone

SFBGames HTML5 (plus Windows/Mac) sound-effect generator in the sfxr/Bfxr family, with a sampler and sequencer still in development. Use it when jsfxr's one-shot oscillator is too thin. The itch page grants CC0 on **sounds you create**. The application's own source license is not published on that page.

## Notes

- Live LICENCE section: generated sounds are CC0 for any purpose, commercial or otherwise. itch Asset license field matches: Creative Commons Zero v1.0 Universal
- That grant is on output, not on redistributing the ChipTone app. Tool-vs-output split is explicit for sounds and silent for the Haxe/OpenFL source
- Status on itch: In development. Expect UI and sequencer changes
- Descended from as3sfxr / sfxr / Bfxr. jsfxr remains the faster "press Pickup and export WAV" option
- Runs in browser; desktop builds are optional
