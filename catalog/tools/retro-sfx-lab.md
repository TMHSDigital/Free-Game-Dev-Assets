# Retro SFX Lab

Browser-only retro game sound-effect generator with presets for UI clicks, confirms, coins, pickups, jumps, hits, lasers, explosions, and success cues. Users can tune waveform, frequency sweep, duration, noise, bit depth, volume, attack time, and decay shape, then export a single WAV or batch-export five variations as a ZIP. The batch ZIP includes a usage/license README and `settings.json` so the exact variation parameters can be reproduced or kept with a project. Everything runs locally; there is no signup, upload, account, or server processing.

## Notes

- The live tool is a self-contained HTML/JavaScript page mirrored under CC0 in the publisher's CircuitUI-SFX repository.
- Generated sounds are user output and may be used in commercial and non-commercial projects according to the tool page; attribution is appreciated but not required.
- Shareable URLs encode the exact parameter set, so a sound can be kept in a design document or recreated later.
- Compared with jsfxr-style tools, the main workflow difference is one-click batch export of multiple small variations plus license/settings metadata in the ZIP.
- Source: the publisher submitted this entry and operates the linked tool.
