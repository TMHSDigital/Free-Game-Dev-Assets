# SVGcode

Progressive Web App (repository tomayac/SVGcode, copyright Google LLC) that converts raster images such as JPG, PNG, GIF, WebP and AVIF to colour or monochrome SVG, using Potrace-based tracing plus SVGO optimisation. Use it at svgco.de or install it from the Microsoft Store on Windows. Useful for turning sketches and logos into scalable UI art.

## Notes

- The GPL covers the web app. SVGs you trace from your own images are your output. Redistributing a modified SVGcode is the GPL event
- The README gives the licence as "GNU General Public License v2.0" and explains it follows Potrace. The source headers settle the version as GPL-2.0-or-later
- Tracing does not change who owns the input. Vectorising someone else's logo is still their logo
- Repository last pushed 2026-09-15
