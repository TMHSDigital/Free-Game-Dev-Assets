# Pixelorama

Open-source pixel art and animation editor with tileset-oriented features. MIT. The editor license is not a license on the sprites you paint.

## Notes

- itch page and GitHub `Orama-Interactive/Pixelorama` LICENSE both say MIT
- `.pxo` is the native project; export PNG sheets for engines
- Command-line export exists for bulk pipelines
