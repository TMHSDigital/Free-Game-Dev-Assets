# G.U.I.D.E.

Godot Unified Input Detection Engine. Structured input mapping and remapping for Godot 4. Helpful for controller configs and Steam Deck-friendly rebinding. Bundled prompt icons are Xelu's CC0 set (separate from the MIT plugin code).
