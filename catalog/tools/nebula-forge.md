# Nebula Forge

Browser-based generator for space nebula backgrounds. It raymarches a 3D volume of gas and dust on your GPU rather than colouring 2D noise, with sliders, a randomise button and PNG export. Nothing is uploaded and there is no signup. It runs as an HTML5 page on itch.io.

## Notes

- `custom`: the page states terms for what you export, not a licence for the generator's code. Exported images are yours for personal and commercial use with no credit owed
- One restriction: the page asks you not to resell the exported images "as their own asset pack". Using them as backgrounds inside a game is the intended use
- The publisher also sells a paid Blender add-on, a motion pack and pre-rendered layered packs. Only the browser generator is covered here
- The page discloses that the code and interface text were developed with AI assistance. The images are rendered by the procedural algorithm, not an image-generation model
- New tool: the itch page shows it updated 17 days before 2026-09-30. There is no source repository to read maintenance from
