# GDevelop

An open-source, no-code game engine for 2D and simple 3D games, with an event system instead of scripting and exports to web, desktop and mobile.

## Notes

- The MIT licence covers the core, game engine, editor and extensions. The GDevelop name and logo are not covered, and online services are a separate subscription.
