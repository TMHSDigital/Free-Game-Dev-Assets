# Dialogic

Visual dialogue and timeline editor for Godot. Useful for in-game notifications, tickets, or narrative UI without building a dialogue system from scratch. Dialogic 2 requires at least Godot 4.5. Keep the MIT notice if you redistribute addon sources.

## Notes

- README: Godot 3.x used Dialogic 1.x; current tree is Dialogic 2
- Software license is MIT; it does not license your written dialogue content
- AssetLib / git submodule install; pin a release for shipping projects
