# Sollumz

Blender 4+ add-on that imports, exports, and authors GTA V format drawables, collisions, archetypes, and (partial) maps. This entry is the **plugin's GPL-3 software license**. It is not a catalog of GTA V assets and not a commercial grant for Rockstar files.

## Notes

- `commercial: true` means you may run this GPL program in a commercial studio, same class of claim as GIMP. It does **not** mean exported GTA V rips are yours to ship.
- Meshes you model yourself follow the same idea as other GPL editors: the program license is not the mesh license. Sollumz has no FAQ sentence that says "exports are yours"; that part is inferred from GPL-on-an-editor, not quoted.
- Importing a drawable from a GTA V RPF does not change ownership. Convert original CC0/CC-BY work (Kenney, KayKit, and similar verified packs), not game files.
- README lists YDD, YDR, YFT, YBN, YTYP, YCD, and partial YMAP. Wiki: [docs.sollumz.org](https://docs.sollumz.org/)
- README recommends CodeWalker (Discord). This catalog does **not** list CodeWalker: no `LICENSE` file on GitHub, and it reads GTA V archives. Owning GTA V is not a redistribution license.
- Distributing a modified Sollumz add-on is GPL-3. That is separate from shipping a game that contains meshes you authored.
