# Creature 2D Runtimes (Godot)

Godot plugin/runtime for Creature mesh-deformation 2D animation. **Apache 2.0** for users without a paid Creature editor license (Creature owners get a separate more permissive runtime license). Editor is paid — this entry is the **runtime**, not free Creature content.
