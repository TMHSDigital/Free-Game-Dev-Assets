# ProtonScatter

Godot 4 MIT scatter addon for procedural 3D prop and foliage placement (modifier-stack style). Keep the MIT notice if you redistribute the addon sources. The addon license is not a license on the meshes you scatter.

## Notes

- Godot 4 addon; pin a release
- Pair with Kenney/Quaternius kits when you need CC0 meshes to actually instance
