# func_godot

Godot 4 add-on that imports Quake `.map` files, as written by [trenchbroom](trenchbroom.md), into Godot scenes with meshes, collision and entities. It is the usual bridge for building Godot levels in TrenchBroom.

## Notes

- MIT; the notice travels with the add-on source if you redistribute it
- Godot 4 only, per the repository description
