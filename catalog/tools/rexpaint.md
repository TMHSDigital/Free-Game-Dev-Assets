# REXPaint

ASCII and ANSI art editor from Grid Sage Games, the studio behind Cogmind. It was built as an in-house tool for roguelike development. Use it for character-cell maps, UI layouts and mockups, with layers, palette swaps, custom fonts and tilesets. It saves a compact native `.xp` format, which has community loaders for many languages, and exports PNG, ANS, TXT, CSV, XML and more.

## Notes

- `custom`: proprietary freeware. The licence in `REXPaint-README.txt` and on the downloads page allows free use of the program and commercial use of what you make with it. No credit is asked for
- Conditions: REXPaint may not be sold, and may not be redistributed over public channels. Link to the official page rather than bundling the program with your game. Private copies are allowed if all files are unchanged
- Windows only; runs under Wine on Linux. Newer macOS needs Crossover
- Current version 1.70 (240110, i.e. 2024-01-10). There is no public repository; the release history lists 1.60 (201011) before it, so updates are occasional
- Fonts on the Resources page from other users carry their own licences (some are CC BY 3.0)
