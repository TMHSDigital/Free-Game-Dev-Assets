# Bosca Ceoil Blue

Beginner-friendly pattern sequencer for writing game music, a Godot-based port of Terry Cavanagh's Bosca Ceoil by Yuri Sizov. This is the maintained line: the original `TerryCavanagh/boscaceoil` repository is archived on GitHub (read 2026-09-26), while Blue runs on Windows, macOS, Linux and in the browser.

## Notes

- **Which Bosca Ceoil:** this entry is the Blue port. The original Adobe AIR program is not listed separately; its repository is archived and Blue reimplements it
- Exports WAV, MIDI and XM per the itch page (XM is not in the catalog's format list, so `formats` leaves it out)
- The MIT licence covers the program. Blue's `LICENSE` also carries the original Bosca Ceoil BSD-style notice for the code it reimplements; keep both if you redistribute the program
- The author, in the itch comments, on music made with it: "The tool is provided under the MIT license. This means that you can use it for both non-commercial and commercial work"
