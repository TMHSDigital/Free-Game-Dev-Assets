# Multipaint

Paint program that enforces the colour limits of 8-bit and 16-bit machines: Commodore 64, Plus/4 and VIC-20, ZX Spectrum, MSX, Amstrad CPC, Amiga, Atari ST and others. It emulates colour clash, and it exports native formats, executables and source for the target platform. It is written in Processing (Java) by Tero Heikkinen and is actively developed; version 2026.1 is dated 2026-06-08.
