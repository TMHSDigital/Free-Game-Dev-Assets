# sfxr

DrPetter's original 2007 Ludum Dare sound-effect generator (win32 zip + SDL tarball). This is the ancestor of [jsfxr](jsfxr.md), [bfxr](bfxr.md), and [chiptone](chiptone.md). Project page: source is MIT, "free to use it for anything you please". That sentence is about the *code*. WAV output ownership is not stated. Prefer jsfxr in a browser and ChipTone when you need a quoted CC0 grant on generated sounds.

## Notes

- Page still hosts `sfxr.zip` (win32) and `sfxr-sdl-1.2.1.tar.gz`. Old tool; expect DPI/audio-device pain on modern Windows
- jsfxr's Unlicense is the *port's* license, not a restatement of this MIT file
- Checklist: MIT named on the project page, commercial use of the *code* implied by MIT, no NC/ND, not a marketplace, named author, not blocklisted, tool vs WAV unquoted
