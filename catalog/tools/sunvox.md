# SunVox

Modular synthesizer and pattern-based tracker from Alexander Zolotov (WarmPlace). You wire synth and effect modules into a graph and sequence them in tracker patterns. It is small and fast, runs on very old hardware, and does well at electronic music, generative loops and sound design. It exports WAV (including multitrack) and MIDI. It is actively developed; the latest release is 2.1.4d (29 Dec 2025).

## Notes

- `custom`: proprietary freeware. It is free on Windows, macOS and Linux (and Windows CE), and paid on iOS and Android. This entry covers only the free desktop downloads
- The bundled licence (`docs/license/sunvox.txt`) puts no restriction on content you create, and allows free redistribution of the program
- Bundled codecs (libvorbis, libFLAC, Tremor) and contributed modules have their own files in `docs/license/`
- A separate SunVox library lets a game play `.sunvox` projects at runtime. Its page says you can use it in commercial products, but also "read the license file" inside `sunvox_lib-2.1.4d.zip`, which was not read on 2026-09-30. Check that file before shipping the library; rendered audio does not need it
- The site says that since 2024-12-27 Google does not allow buying apps from developers registered in Russia, so the paid Android version is sold through a workaround by email
