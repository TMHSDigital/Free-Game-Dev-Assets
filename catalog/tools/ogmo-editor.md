# Ogmo Editor 3

Free 2D level editor with tile, grid, decal and entity layers. Levels save as plain JSON, so any engine can read them with a small loader. The Community Edition on GitHub is the maintained line of the project.

## Notes

- Commercial use of the editor is stated outright on the homepage, and the source is MIT
- Development is slower than [ldtk](ldtk.md) or [tiled](tiled.md): the last push to `Ogmo-Editor-3/OgmoEditor3-CE` was on 2024-06-19 (read 2026-09-26). That is under the three-year line for `maintenance: inactive`
- Levels are your own data; the MIT licence applies to the editor
