# Godot Volumetric Cloud Demo

Clay John’s MIT demo of ray-marched volumetric cloudscapes in Godot sky shaders, with sun-driven time-of-day. Reference implementation for custom skies — not a one-click addon.

## Notes

- Targets Vulkan; treat as a learning / fork base rather than a drop-in Asset Library plugin
- Complements [sky3d](sky3d.md) (full day-night addon) when you want cloud raymarching specifics
- Keep MIT copyright notice with redistributed shader code
