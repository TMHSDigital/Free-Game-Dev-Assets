# Unity Labs VFX flipbooks

Smoke / fire / explosion image sequences from Unity Labs Paris (Thomas Iche, 2016). Released as CC0 for use in projects, as raw frames or assembled flipbook sheets. Not the Unity Companion License. Engine-agnostic textures.

## Notes

- Canonical URL this session is `unity.com/blog/engine-platform/...`. The older `blog.unity.com/engine-platform/...` host returned HTTP 403.
- Live text names CC0 and "use them in your projects." It does not repeat a Unity-engine lock.
- Sequences: HDR linear EXR or assembled flipbook sheets (page also discusses UNORM packs). Confirm the zip you grab.
- Experimental VFX Toolbox Image Sequencer is a Unity helper for assembling sheets. The textures themselves are still CC0 files.
- Do not confuse with Unity Companion / Starter Assets (engine-locked). See [`docs/high-risk.md`](../../docs/high-risk.md).

## Evidence

- Live Unity blog (2026-08-29): "share with you under CC0 license. Feel free to use them in your projects!"
