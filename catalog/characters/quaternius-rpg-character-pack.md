# Quaternius RPG Character Pack

Six rigged, animated, textured fantasy characters. Overlaps [KayKit Adventurers](kaykit-adventurers.md) and Universal Base + outfits. Useful when you want clips already on the mesh instead of a retarget pipeline.

## Notes

- Older pack (page dated November 2020). Prefer Universal Base + UAL when you need a modular pipeline.
- Textured. FBX / OBJ / Blend / glTF.
- Humanoid. UAL retarget is the usual Quaternius path if the included clips are too thin.
