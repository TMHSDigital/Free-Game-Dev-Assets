# CharMorph

Blender character tool reimplementing MB-Lab-style morphing (no MB-Lab *code*). **Not a safe CC0 default, and the base you pick decides everything.** Every licence involved allows commercial use, but the two `mb_*` bases are **AGPL-3.0** and CharMorph's own licence file says a model made from them "must be distribuited under AGPL 3": a character from `mb_female` or `mb_male` cannot ship in a closed-source game. The CC-BY bases (Antonia, Reom) can, with credit. Addon code is **GPL-3**. Prefer [makehuman](makehuman.md) / [mpfb](mpfb.md) for commercial closed-source mesh exports.

## Notes

- **Pick a CC-BY base for a closed game.** CharMorph's licence file: "Please use CC-BY models if you want to avoid it" (the AGPL spreading to output models)
- Open each character's `license.txt` or `config.yaml` in [CharMorph-db](https://github.com/Upliner/CharMorph-db) before exporting. On 2026-10-04 the bases were `antonia`, `mb_female`, `mb_male` and `reom`
- `mb_female`, `mb_male` = AGPL-3 (`mb_male/config.yaml`: "license: AGPL3"; it has no `license.txt`). The exported model is AGPL too, so you must offer its source and keep the copyright notice
- Antonia = CC-BY-3.0. Credit the authors named in its `config.yaml`
- Reom = CC-BY per its `config.yaml` (`license: CC-BY`, no version stated); it has no `license.txt`. Credit the authors named in its `config.yaml`
- 2D renders are treated differently: CharMorph's licence file says rendered images and videos of a scene with these models "are not considered a derived product" of the database. That helps pre-rendered sprites or cutscenes, not a shipped 3D mesh
- Maintenance: GitHub API on 2026-10-04: CharMorph not archived, last push 2025-05-29; CharMorph-db last push 2024-07-23
