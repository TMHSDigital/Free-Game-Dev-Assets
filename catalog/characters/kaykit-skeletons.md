# KayKit Skeletons Character Pack

Four stylized low-poly skeletons (two more on the paid extra tier), rigged and animated, plus 10+ weapons and accessories. Built to take [KayKit Character Animations](../animation/kaykit-character-animations.md) on the same Rig_Medium / Rig_Large split as Adventurers. Name-your-price; free tier is the core four.

## Notes

- Single gradient atlas (1024, downsample to 128). Same atlas trick as Adventurers.
- Basic locomotion ships in the pack. Pull the free animation library for melee, ranged, and hits.
- Author ask: do not resell unmodified copies. CC0 still applies.
