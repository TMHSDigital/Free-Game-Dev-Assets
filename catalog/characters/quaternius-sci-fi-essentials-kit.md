# Quaternius Sci-Fi Essentials Kit

Futuristic kit with animated robot enemies, guns, screens, and crates (60+ models). This is the sci-fi *character* close versus Rocketbox office humans. Guns and props ride along in the same zip. Designed to sit in front of the Modular Sci-Fi MegaKit environment, which is not this entry.

## Notes

- Textured. Source SKU adds engine projects and custom shaders (Unity URP, Unreal, Godot) per the pack page. Standard is FBX / OBJ / glTF.
- Robot clips are on these rigs. UAL is humanoid. Do not expect a clean retarget between them.
- Mixed kit, same cataloguing choice as Cube World: the gap is sci-fi enemies, so it lives in characters/.
