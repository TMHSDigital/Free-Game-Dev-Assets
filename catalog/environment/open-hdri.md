# Open HDRI

Second CC0 HDRI publisher besides Poly Haven. Real-world captured unclipped linear 32-bit EXRs (library claims up to 29K). Author Grzegorz Wronkowski also runs HDRMaps; this catalog uses the Open HDRI CC0 grant, not a second "independent" HDRI house.

## Notes

- Homepage grant covers the library as CC0. Confirm the badge on a given EXR if a listing ever diverges.
- No account, no ads. Hosting is Patreon/Ko-fi funded.
- HDRMaps freebies are the same photographer. Do not add a sibling HDRMaps entry for the same grant.
- Pair with [poly-haven](poly-haven.md) when you want a second CC0 IBL vendor.

## Evidence

- Live homepage (2026-08-29): "released as CC0 for unrestricted use"
- Same page og:description (2026-08-29): "completely free for personal and commercial use"
