# Soundza

Free library of sound effects, music loops, ambience, one-shots and vocal chops, downloadable as WAV or MP3. The terms allow use in commercial games with no credit owed, and say shipping a sound inside a game is fine. The site also has a REST API and an MCP server for search and download, and a free AI sound effect generator.

## Notes

- **No attribution:** the terms say no credit is required
- **Inside a game is fine; standalone redistribution is not.** Sounds may not be shared, resold or given away as standalone files or in a sample pack, loop library or sound kit, and may not be uploaded to another sound marketplace
- **No AI training:** the terms bar using the sounds to train, fine-tune or otherwise develop any AI or machine-learning system
- Some library sounds are AI-generated and are labelled as AI on their pages. The separate [sound effect generator](https://soundza.com/tools/sound-effect-generator) makes new clips from a text prompt; this entry covers the downloadable library
- Developer access: REST API at https://api.soundza.com/v1 (docs at https://soundza.com/developers) and an MCP server at https://mcp.soundza.com/mcp; search works without a key
