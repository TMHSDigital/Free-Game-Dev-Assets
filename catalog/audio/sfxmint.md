# SFXMint

Library of game and app sound effects (UI clicks, coins, jumps, impacts, ambience and more) dedicated to the public domain under CC0 1.0, downloadable as WAV or MP3. Sounds can be looked up by the game or app event they are for, or as a matching set for a game genre. The site also has a JSON API and an MCP server for search and download that work without a key.

## Notes

- **Every library sound is AI-generated or procedurally synthesized.** The licence page says AI sounds are made with Stability AI models under the Stability AI Community License; check your store's AI disclosure rules (Steam asks for it)
- **Download allowance, not a licence limit:** the site allows 3 library downloads a day, with or without a free account; ZIP packs come with a purchase. The licence page says this limits the download service, not the licence
- **Paid tier:** an AI Studio generates new sounds from a text description. Generations made or downloaded with a credit or a plan are CC0; a free account's first 3 generated downloads are for personal, non-commercial use only. This entry covers the free library
- Audio URLs are permanent and CORS-enabled, so web games can hotlink them
