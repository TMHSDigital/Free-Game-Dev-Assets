# SoundBible

Free sound-clip site with WAV and MP3 downloads. Each sound carries its own licence label on its page. Most are Creative Commons Attribution 3.0, some are public domain, and some are Noncommercial 3.0, Sampling Plus 1.0 or "Personal Use Only," which are not usable in a commercial game. Filter per sound; there is no site-wide grant.

## Notes

- `commercial: varies`: the About page itself limits commercial use to Attribution and Public Domain sounds. A listing crawl on 2026-09-30 found Attribution 3.0 and Public Domain on the Royalty Free Sounds pages, and Noncommercial 3.0, Sampling Plus 1.0 and Personal Use Only on the general Sound Effects pages
- Usable in a commercial game: Attribution 3.0 (credit the named author, CC BY 3.0) and Public Domain. Skip Noncommercial, Personal Use Only and Sampling Plus
- `attribution_required: unknown` because credit is per file (CC BY needs it, public domain does not), the same case as [freesound](freesound.md)
- Read the licence on each sound's own page, not the listing, before you ship it. The catalog has not checked uploads' provenance; SoundBible is not the recording author for most clips
- The site also links a paid premium store; those are separate terms
- Re-checked 2026-10-04: About page unchanged. Still open: licence and credit are per sound (CC BY 3.0, public domain, NC, Sampling Plus, Personal Use Only), so neither can be settled site-wide
