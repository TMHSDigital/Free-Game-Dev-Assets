# Quaternius Ultimate Animated Character Pack

50+ animated low-poly characters with many baked animations, shipped as FBX, OBJ and Blend. Useful as ready-to-play animated placeholders or as source clips to retarget. Animations are per-character, not on one shared rig, so retargeting needs work.

## Notes

- Page lists 52 animated, textured models; characters carry their own skeletons
- Not a universal rig: for retarget-friendly clips prefer the Universal Animation Library
- Attribution example (optional): `Animations by Quaternius (CC0)`
- Quaternius published a separate Quaternius Asset License (QAL v1.0, dated 2026-08-28) that says it governs future releases and that earlier versions are not changed retroactively. This 2018-2019 pack page still shows CC0. Keep a copy of the pack page or download date with your project files.
