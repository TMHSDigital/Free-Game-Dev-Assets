# Quaternius Background Posed Humans Pack

A set of 20 posed low-poly humans with 8 hairstyles in FBX, OBJ and Blend, for crowds and scene dressing. Static poses rather than motion clips, so it suits background filler more than gameplay characters.

## Notes

- Page lists 28 models (August 2018); description says 20 posed humans plus hairstyles
- Static poses; no locomotion or action clips
- Attribution example (optional): `Animations by Quaternius (CC0)`
