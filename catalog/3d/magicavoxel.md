# MagicaVoxel

Closed-source freeware voxel editor (Win/Mac, 0.99.7.2 as of 2025-07-12). Site license: free to use for any project; credits appreciated; do not sell or distribute the software. That is a tool license. It does not spell out exported-mesh ownership in those words; the only stated restriction is redistributing the editor.

## Notes

- Content is loaded from `mv_main.html`; the index shell has no license text
- Enable IO, Export, Local if exported meshes are not centered
- Credits are "appreciated", not required
- Use [goxel](../tools/goxel.md) when you need an auditable GPL editor instead of this freeware binary

## Evidence

- Live [mv_main.html](https://ephtracy.github.io/mv_main.html) (2026-08-24): "Free to use for any project."
- Same page (2026-08-24): "Selling or distributing the software (original or modified) in other packages are disallowed."
