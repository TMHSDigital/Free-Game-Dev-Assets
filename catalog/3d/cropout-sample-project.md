# Cropout Sample Project

Epic's free top-down casual RTS sample: a family-friendly farming and village game built to show cross-platform best practice from low-spec mobile up to consoles and PC. It demonstrates Common UI, Enhanced Input and Geometry Script, and is built in Blueprints. Delivered as an Unreal project through Fab and marked UE-only.

## Notes

- Contents: Blueprints, materials, VFX, stylized characters, buildings and procedural island generation for a small resource-gathering RTS
- UE versions: the Fab listing's "Unreal Engine versions" field read 5.2 – 5.8 on 2026-10-13 (first published June 2023, last update September 22, 2026)
- Licence: Fab Standard License, free on both tiers, and the description states "UE-Only Content - Licensed for Use Only with Unreal Engine-based Products", hence `engine_lock: unreal`. The stylized art cannot be exported to other engines
- Redistribution: this is Epic content and may not be redistributed in source form or committed to a public repository. Epic's content licence says you "may not Distribute Licensed Content in source format to third parties except to employees, affiliates, and contractors who are utilizing the Licensed Content in good faith to develop a Project on your behalf"
- Gotchas: the project is pure Blueprint, which makes it approachable but means logic changes are graph edits rather than code diffs; touch and gamepad input paths both exist, so test both after edits. Epic's landing page is unrealengine.com/cropout
