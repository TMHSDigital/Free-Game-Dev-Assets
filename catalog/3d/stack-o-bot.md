# Stack O Bot

Epic's free third-person puzzle platformer sample, rebuilt from the ground up for Unreal Engine 5.6. It includes a playable platforming character, physics-based puzzle mechanics, procedural level-building tools, modular objective systems and UV-less materials, with in-game developer commentary explaining the design. Runs from mobile to high-end PC with touch, gamepad and keyboard input. Delivered as an Unreal project through Fab.

## Notes

- Contents: playable robot character, physics puzzles, procedural environment tools, objective and progression systems, commented Blueprints and materials
- UE versions: the Fab listing's "Unreal Engine versions" field read 5.0 – 5.8 on 2026-10-13. The description says the project "has been fully rebuilt from the ground up for Unreal Engine 5.6" and that the older sample needs an engine version before 5.6, so 5.0 to 5.5 get the original project and 5.6 onward get the rebuild
- Licence: Fab Standard License, free on both tiers. The current description has no "UE-Only Content" line, so `engine_lock` is omitted. Open question: Epic marks Lyra and Cropout UE-only but not this listing; confirm on the listing before exporting the robot or props to another engine. Kept at needs-review for that reason

- Gotchas: the pre-5.6 and 5.6+ versions are different projects, so tutorials written for the original Stack O Bot will not match the rebuild
