# Smithsonian Open Access

Museum 3D scans and media released under CC0 when marked with the Creative Commons Zero icon. High-accuracy heritage assets. Heavy for real-time use; better as reference, cinematics, or decimated in-game props. Not every Smithsonian page is CC0. Filter to CC0-marked items.

## Notes

- Open Access hub: [si.edu/openaccess](https://www.si.edu/openaccess). 3D viewer: [3d.si.edu](https://3d.si.edu)
- Binding CC0 wording is in Smithsonian [Terms of Use](https://www.si.edu/termsofuse), not the marketing banner
- Terms warn CC0 covers copyright only; publicity, privacy, and third-party rights can still apply
- The Open Access pages refuse scripted requests (403 on 2026-09-25; a server error on 2026-09-24) but load in a browser

## Evidence

- Live [Terms of Use](https://www.si.edu/termsofuse) (2026-09-25): "Creative Commons Zero (CC0) license"
- Same page (2026-09-25): "may be used for commercial and noncommercial purposes without fee"
- Live Open Access hub (2026-09-25): "download, share, and reuse millions of the Smithsonian’s images"
- Live [Open Access FAQ](https://www.si.edu/openaccess/faq) (2026-09-25): "We have released these images and data into the public domain as Creative Commons Zero (CC0)"
