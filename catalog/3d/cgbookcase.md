# cgbookcase

566 CC0 PBR texture sets (photogrammetry, procedural, and approximated), including 4K/8K rocks, brick, fabric, and manhole-cover decals. Complements ambientCG when you need extra photoscanned surfaces. Run by Dorian Zgraggen. Patron/Ko-fi is optional and is not a license condition.

## Notes

- License statement lives on the textures listing, not on a `/license` URL (that path 404s)
- Map stacks are the usual PBR set. Confirm DirectX vs OpenGL normals per download
- Pair with [poly-haven](../environment/poly-haven.md) for HDRI. This site is albedo/roughness/normal/height, not lighting
- Seamless-maker companion tool is on Codeberg (`dutlef/texture-tool`). That tool has its own license; this entry is the texture library
