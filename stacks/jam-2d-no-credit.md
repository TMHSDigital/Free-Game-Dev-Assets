# Game jam: 2D with nothing to credit

For a jam entry in any engine, where every minute spent on a credits screen is a minute not spent on the game. Every pick is a direct download with no account, and none of them asks for credit, so the "what this set owes" box below should stay empty. One tile set covers the whole game in a single 1-bit style, so the art never clashes, and the sound comes from packs and a generator rather than a library to search.

## Art

- **Tiles, characters and items:** [Kenney 1-Bit Pack](../catalog/2d/kenney-1-bit-pack.md). 1078 tiles on a 16x16 grid in one 1-bit style: walls, floors, props, creatures and glyphs, enough for a whole game in one look.
- **Menus and HUD:** [Kenney UI Pack](../catalog/2d/kenney-ui-pack.md). 430 buttons, panels and sliders for a title screen and a HUD in minutes.
- **Controls screen:** [Kenney Input Prompts](../catalog/2d/kenney-input-prompts.md). Over 1500 button glyphs for keyboard, mouse, touch and every common controller, for a "how to play" screen.
- **Effects:** [Kenney Particle Pack](../catalog/shaders-vfx/kenney-particle-pack.md). 80 particle sprites (sparks, glows, soft blobs) for hits, pickups and explosions.

## Audio

- **Music:** [5 Chiptunes (Action), SubspaceAudio](../catalog/audio/subspaceaudio-5-chiptunes.md). Five looping tracks, Title Screen, Level 1 to 3 and Ending: a whole small soundtrack.
- **Win and lose cues:** [Kenney Music Jingles](../catalog/audio/kenney-music-jingles.md). 85 short stingers for level complete, game over, pickups and menu confirms.
- **Menu sounds:** [Kenney Interface Sounds](../catalog/audio/kenney-interface-sounds.md). 100 clicks and confirms for every button in the UI pack.
- **Hits:** [Kenney Impact Sounds](../catalog/audio/kenney-impact-sounds.md). 130 punches, thuds and impacts for combat feedback.

## Fonts

- **Title and HUD text:** [Kenney Fonts](../catalog/fonts/kenney-fonts.md). Twelve pixel and display faces that match the lettering in Kenney's packs.

## Tools

- **Any sound the packs miss:** [ChipTone](../catalog/tools/chiptone.md). A sound-effect generator that runs in the browser and exports WAV; the sounds you make are yours to ship.
